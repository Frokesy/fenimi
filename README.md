# Fenimi Fashion

A buildless interactive design prototype. Run `npm run dev` and open http://localhost:5173. Run `npm run check` for syntax and catalog checks.

Includes collection filters, product details, size selection, cart quantities, full-payment and deposit sample checkout, bespoke quote requests, a procedural Three.js mannequin with three compatible demonstration outfits, and an in-memory admin product form. Admin photo-to-3D processing, approval and failure are explicitly simulated. Uploaded photos remain local object URLs. Orders and personal details are never persisted or submitted. Refresh resets the collection and bag.

Real commerce, admin authentication, payment-provider integration, fulfillment fees, deposit collection and real garment reconstruction are outside this prototype. All products, prices and dates are illustrative. The procedural garments are schematic, not photorealistic replicas or fit predictions.

The editorial sample photograph is from Unsplash (photo-1539109136881-3be0616acf4b). Product illustrations and mannequin geometry are original code-created assets. Three.js 0.170.0 is vendored under its MIT license. Fonts are loaded from Google Fonts with system fallbacks.
